# 0033 网关内存指标的读取接口
- 状态：提议
- 日期：2026-10-06；提议人：C；待 D（前端绑定与演示者视图）、E（可观测性与隐私）评审

## 背景
产品书 08 FR-AIG-08 要求演示者视图和设置页可以查看各接口调用次数、成功率、P50/P95 与熔断状态。
网关已有 `HttpGateway::metrics()` 和 `models()`，但 Tauri 未提供读取命令，前端无法取得这些内存指标。

## 决策
1. 新增只读命令 `ai_gateway_metrics`，无参数，返回 `{ apis, models }`。命令取得一次当前网关的 `Arc`，
   两份列表均来自该网关；并发请求期间字段可能继续变化，不承诺事务快照。读取不发 HTTP 请求，不扣预算，不读写数据库。
2. `apis` 按接口名称排序，含 `api`、`calls`、`ok`、`success_rate`、`p50_ms`、`p95_ms`、`breaker_open`。
   成功率为 `ok / calls`（0～1）；延迟来自最近最多 500 次成功调用。没有发生调用的接口不出现在列表里；
   没有成功调用时延迟为 `null`。分位数、重试计数和熔断判定复用网关原有口径。
3. `models` 按配置优先级排列，含 `model`、`available`、`breaker_open`、`success_rate`、`p50_ms`。
   成功率与 P50 使用最近 20 次调用；尚未调用时为 `null`。`available` 沿用网关模型发现口径，不额外探测。
4. 无配置的离线网关返回两份空列表；已配置但未调用的模型仍可列出。命令仅返回模型标识和计量字段，
   不返回服务地址、密钥、提示词、用户输入或模型回复。
5. 指标不落盘。Hub 重启或保存配置而创建新网关时清空；今日预算仍按原有 `inherit_budget` 机制继承，
   指标与预算的生命周期不同。前端不应将这些计数称为“今日调用数”。
6. 整数计数与毫秒按 ADR 0027 显式导出为 TypeScript `number`，可空的分位数与成功率为 `number | null`。
   前端使用生成的 `commands.aiGatewayMetrics()`；演示面板与设置页的展示由 D 接入，本次不标为完成。

## 影响
产品书 10 第 5.1 节 AI 命令组补充 `ai_gateway_metrics` 的返回字段；08 FR-AIG-08 补充更换网关配置时清空指标的口径。
C-03 的指标读取接口完成；演示者视图与设置页展示仍待 D。没有修改数据库或出网协议。

## 验证
Hub 命令层测试覆盖离线空列表、未调用的模型、成功和失败计数、熔断、读取不增加请求或预算、
序列化结果不含测试密钥或正文，以及新网关清空指标但保留预算。前端绑定测试守住 `number` / `null` 契约。
