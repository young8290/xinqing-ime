# 0043 日程待办提醒文案用户覆盖

- 状态：提议；2026-10-06；C 提议，待 E/D 评审

## 决策

C-05/C-06 共用提醒服务读取用户 `templates/ui_copy.toml` 的 `[notify]` 提醒字段，要求顶层正整数版本、全部所需字段非空、出厂禁用词校验通过。每个字段只能使用现有对应占位符，并须保留所需参数；未知变量或未配对括号拒绝。读取或校验失败整体回退出厂提醒文案，修改后重启生效，日志不含用户内容。

按 DS-COPY-08，固定通知文案同时拒绝已知情绪状态词（情绪、低落、烦躁、疲劳、犹豫、流畅及天气状态名），避免系统通知暴露感知状态。用户日程标题与地点依旧按已确认内容渲染。

用户数据目录不可用时提醒仍尝试出厂目录，避免影响到期提醒。仅文案允许覆盖；提醒时刻、按钮动作、系统通知隐私、数据库和命令契约不变，其他安全字段不会被此加载器消费。出厂内容未修改。

## 影响

产品书 10 第 7 节、15 第 5 节补充提醒文案字段级校验；属于 C 的提醒服务接线，不代替 D 的其他 UI 文案覆盖。

## 验证

测试验证用户标题与待办汇总生效、时间地点渲染与按钮动作不变，以及空白/禁用词/未知或缺失占位符/损坏括号/非法版本/非 UTF-8 回退。
`schedule.ics_description` 也通过独立加载器允许覆盖，要求版本、非空与禁用词校验；失败不会抹掉有效的提醒文案，导出格式与字段不变。
