# 0022 对话快捷指令的会话对话方式
- 状态：提议
- 日期：2026-10-05；决策人：C（对话服务）；待 D（对话窗口按钮、`bindings.ts` 契约）、E（两段新提示词，按 15 第 5 节须 E 参与评审）评审

## 背景
05 FR-CHT-06 有四个快捷指令：📝 写成情绪日记（进入 FR-DIA-01）、🌬 陪我呼吸 1 分钟（本地动画）、💬 我只是想吐槽
（“**本会话**切换为只倾听风格：只共情和复述，不给建议”）、🧭 帮我理一理（引导拆成“发生了什么 / 我的感受 / 我能做的一小步”）。
产品书 08 第 4 节没有后两项的提示词原文，09 的 `chat_session` 也没有存这种状态的列。

xinqing-ime#51 的第一版做了 `chat_shortcut(shortcut)` 命令，把一句硬编码在 Rust 里的“隐藏引导语”返回给前端，由窗口“作为下一轮对话的
隐藏指令接入”。但 `chat_send` 只收用户消息，前端只能把这句话当成用户输入发出去并写进历史，和注释相反；而且只作用一轮，
不是“本会话”；提示词绕开了 `hub_templates/prompts/` 和评审流程。

## 决策
1. **对话方式是会话的属性**：迁移 0003 给 `chat_session` 加 `mode TEXT NOT NULL DEFAULT 'normal'`（`normal` / `vent` /
   `organize`），`domain::chat::ChatMode` 与之对应。切换后整段会话有效，直到切回 `normal`；新会话（含 6 小时后自动新开的）是 `normal`。
2. **提示词放模板**：`hub_templates/prompts/chat_vent.md`（P-CHAT-VENT）、`chat_organize.md`（P-CHAT-ORGANIZE），格式同其他提示词
   （首行版本号，只读出厂版本）。系统提示词 = P-CHAT 原文 + 对话方式的一段，**不改 P-CHAT 原文**，边界条款照常在前。
   `prompt_ver` 记成 `P-CHAT v1 + P-CHAT-VENT v1`，评测和消息记录能追到用的哪一版。
3. **安全优先**：安全模式（P-CHAT-SAFE）不叠加对话方式；危机识别（本地词表 + Q-CRISIS）对每条用户消息照常进行，与对话方式无关。
4. **命令**：`chat_set_mode(session_id, mode)` 切换已有会话；还没有会话时，窗口在 `chat_send` 里带上 `mode`，先切再生成回复。
   `chat_list_sessions` 的每一行带 `mode`，窗口据此显示提示、提供“回到平常聊天”。不再有 `chat_shortcut`。
5. **日记与呼吸是窗口的本地动作**，不经过后端：呼吸动画不出网；日记随 C-10（FR-DIA-01）。

## 影响
- 09 第 3 节 `chat_session` 表结构要加 `mode` 列；08 第 4 节要补 P-CHAT-VENT、P-CHAT-ORGANIZE 两段原文（以本仓模板为准，E 评审后回写）；
  10 第 5.1 节对话命令补 `chat_set_mode`，`chat_send` 增加可选的 `mode`。
- 数据导出（FR-DAT-03）按表整列导出，`mode` 随之导出，不含内容。
- 按钮、“只倾听中”的提示与本地呼吸动画是 D 的对话窗口（D-06）的工作。
