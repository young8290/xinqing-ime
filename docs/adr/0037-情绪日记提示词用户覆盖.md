# 0037 情绪日记提示词用户覆盖

- 状态：提议
- 日期：2026-10-06；提议人：C；待 E（提示词覆盖与校验口径）、D（使用说明）评审

## 背景

产品书 15 第 5 节允许非安全模板的用户同名覆盖，10 第 7 节要求启动加载、失败回退出厂版本。
C-10 日记服务此前只读出厂 `prompts/diary.md`，用户提示词无法生效。

## 决策

1. 日记启动使用 ADR 0034 的 `hub_template_dirs`，P-DIARY 使用 `load_with_fallback`。
   用户文件为 Hub 数据目录 `templates/prompts/diary.md`，同名整体替换，修改后重启生效。
2. 首行须有完整的正整数版本标记 `<!-- version: N -->`，去注释后的正文非空，并含 `{summary}`、`{chat_digest}`。
   读取、UTF-8 或语义校验失败时回退出厂版本，日志仅记录固定文件名，不记录用户正文；出厂文件也不可用时沿用服务不可用的错误路径。
3. 生成草稿仍经过长度、禁用词和中文占比校验；状态摘要同意控制、对话安全模式与危机命中时不出网的流程不变。
   提示词覆盖不增加出网字段，也不改变保存时的来源判断与危机识别。
4. `ui_copy.toml`（空白模板与安全会话标题）、危机词表、禁用词表仍只认出厂文件；本次不接通固定文案覆盖，不改出厂内容。

## 影响

产品书 10 第 7 节、15 第 5 节补充 P-DIARY 的占位符校验及启动回退口径。
不改变数据库、命令、事件、前端绑定。C-10 的其他模板覆盖与跨组评审仍是独立尾项。

## 验证

集成测试覆盖有效版本和四种可选输入组合、注释去除、缺失用户文件、非法版本、缺正文或占位符、非 UTF-8、
出厂文件缺失错误，以及用户固定文案与禁用词表不能替换出厂约束。完整 workspace 测试包含日记服务的同意、安全模式与危机不出网回归用例。
