# 0034 暖心话用户模板覆盖与校验回退
- 状态：提议
- 日期：2026-10-06；提议人：C；待 E（校验口径、提示词覆盖）、D（使用说明）评审

## 背景
产品书 15 第 5 节允许用户目录同名文件覆盖出厂模板，危机词表和禁用词表除外；10 第 7 节要求启动校验，失败回退到出厂版本。
C-04 启动时只构造 `TemplateDirs::factory_only`，因此用户暖心话无法生效；P-COMFORT 也固定读出厂目录。

## 决策
1. 本次只接通 C-04：`comfort.toml` 与 `prompts/comfort.md` 从 Hub 数据目录的 `templates/` 读取，文件缺失时使用出厂版本。
   正式版对应 `%LOCALAPPDATA%\XinQing\hub\templates\`，调试版为 `XinQingDev`；`XQ_HUB_DATA_DIR` 改变数据目录时覆盖目录随之改变。
   不创建目录、不热加载；修改、删除覆盖文件后重启 Hub 生效。出厂目录解析仍沿用 `XQ_HUB_TEMPLATES` 和安装目录规则。
2. 同名文件整体替换，不做逐键合并。两个文件独立校验和回退，坏提示词不会抹掉已通过校验的用户暖心话。
   新增 `TemplateDirs::load_with_fallback`，读取、解析或语义校验失败时仅记录固定模板名，不输出用户正文或解析错误原文。
   若出厂文件本身也无法使用，沿用服务不启动的错误路径，不伪装成加载成功。
3. 暖心话要求正整数版本号、两种风格各六组均非空、句子 id 非空且全文件唯一、每句 6～30 个汉字、
   不含出厂禁用词或“打字”、至多一个感叹号。温柔 `cheer` 组至少一句 ≤15 个汉字，供简洁风格兜底。
   用户文件每组至少一句，不要求出厂资产的 15 句配额。任何一句不通过则整份用户文件回退。
4. P-COMFORT 要求第一行是完整的正整数版本标记 `<!-- version: N -->`，去注释后正文非空，保留
   `{style_block}`、`{summary_json}`、`{recent_texts}` 三个占位符。模型回复仍经过原有输出校验；不改出网字段、同意检查或预算。
   出厂提示词未改动，现有其他提示词的加载方式不变。
5. 禁用词表依然只调用 `factory_path`；用户同名禁用词表不能解除校验。危机词表与安全流程未改动。
   UI 文案、日程、日记、周信、状态解释等其他模块的用户模板覆盖不在本次完成范围内。

## 影响
产品书 10 第 7 节补充 C-04 的逐文件回退、启动生效和语义校验口径；15 第 5 节补充用户暖心话每组至少一句、简洁兜底要求。
C 组交接文档将模板覆盖拆成“C-04 完成、其他模块待接入”，不将整个模板系统标为完成。

## 验证
集成测试覆盖有效覆盖、缺失覆盖、独立回退、TOML 错误、禁用内容、短句、重复 id、缺组、简洁兜底缺失、
提示词缺版本与占位符、非 UTF-8、同名目录和缺失出厂文件；用户伪造禁用词表时仍执行出厂约束。
