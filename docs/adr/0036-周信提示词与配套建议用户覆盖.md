# 0036 周信提示词与配套建议用户覆盖

- 状态：提议
- 日期：2026-10-06；提议人：C；待 E（模板校验与提示词覆盖）、D（使用说明）评审

## 背景

产品书 15 第 5 节允许用户目录同名覆盖非安全模板，10 第 7 节要求启动加载、校验失败回退出厂版本。
周信服务此前只读出厂目录，用户无法自定义 P-LETTER 或配套评语与建议。

## 决策

1. C-10 周信启动使用 ADR 0034 的 `hub_template_dirs` 与 `load_with_fallback`，接通 `prompts/letter.md`、`letter_tips.toml`。
   从 Hub 数据目录 `templates/` 读取，整体替换、逐文件独立回退；修改后重启生效。仅记录固定文件名，不输出用户正文与解析错误原文。
2. P-LETTER 首行须为完整的正整数版本标记 `<!-- version: N -->`，去注释后的正文须非空，并保留 `{style_block}` 与 `{weekly_stats_json}`。
   原有风格、同意检查、仅统计 JSON 出网、预算及生成结果长度/V4/V9 校验不变；出厂提示词内容不改。
3. `letter_tips.toml` 须有正整数版本号，三档 `rest_comment` 均非空；建议须恰好含 `late`、`rest_low`、`hard`、`default` 四组，各一条。
   评语和建议均使用出厂禁用词表校验，不允许用户同名词表解除约束；缺组、重复组、未知组、空白或禁用内容导致整份文件回退。
4. `letter_fallback.md` 仍只读出厂版本，其用户覆盖及占位符语法校验留待后续任务。日记等其他模块也未在本次接通。
   若回退后的出厂文件也不可用，沿用周信服务不启动的错误路径。

## 影响

产品书 10 第 7 节补充两个周信文件的校验口径与独立回退；15 第 1、5 节补充 `letter_tips.toml` 的用户覆盖和四组约束。
不改变数据库、命令、事件或前端绑定；C 交接文档明确记录子任务范围，不将整个 C-10 或模板系统标为完成。

## 验证

集成测试覆盖有效覆盖与渲染、缺失用户文件、逐文件独立回退、缺失/非法版本、缺占位符、非 UTF-8、TOML 错误、
缺组/重复组/未知组、空白、禁用内容、用户伪造禁用词表，以及出厂文件缺失时返回错误。
