# 0039 普通对话提示词用户覆盖

- 状态：提议；2026-10-06；C 提议，待 E/D 评审

## 决策

C-07 接通 Hub 数据目录的 `templates/prompts/chat.md`、`chat_vent.md`、`chat_organize.md`。复用 ADR 0038 的提示词校验：正整数版本、非空正文，普通对话必须保留 `{style_block}`、`{today_summary_block}`、`{memory_block}`。逐文件回退，修改后重启生效，错误日志不包含用户正文。

P-CHAT-SAFE 及求助/安全模式文案始终读出厂目录，安全模式不使用普通对话或快捷指令覆盖。危机词表、禁用词、同意控制、记忆注入与输出校验流程不变；出厂提示词没有修改。

## 影响

产品书 10 第 7 节、15 第 5 节补充普通对话覆盖的校验规则，并明确安全提示词不允许覆盖（安全模式使用受审出厂内容）。真实接口 E-CHAT 与人工审核仍待对应输入。

## 验证

集成测试验证三个用户文件、版本记录、摘要与记忆渲染、独立回退、缺占位符、非 UTF-8、安全提示词覆盖无效和缺失出厂错误。原有对话危机与安全模式回归测试继续执行。
