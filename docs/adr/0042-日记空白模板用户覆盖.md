# 0042 日记空白模板用户覆盖

- 状态：提议；2026-10-06；C 提议，待 E/D 评审

## 决策

C-10 在 ADR 0037 基础上允许 Hub 数据目录 `templates/ui_copy.toml` 的 `diary.blank` 覆盖日记空白模板。校验正整数顶层版本、非空正文、出厂禁用词；读取或校验失败回退出厂空白模板，修改后重启生效。

整个文件解析后只提取日记空白模板；`diary.safety_session` 与其他安全文案不使用用户值，求助会话标题继续只读出厂文件。提示词与空白模板分别回退。UI 文案其他模块的覆盖由各负责人另行推进，不在本次 C 开发范围内。

## 影响

产品书 10 第 7 节、15 第 5 节补充局部消费 `ui_copy.toml` 和安全文案例外的口径。不改出厂文案、日记命令、同意控制和危机流程；真实接口与人工评审仍待输入。

## 验证

验证有效空白覆盖、求助标题覆盖无效、非法版本/缺字段/空白/禁用内容/损坏 TOML/非 UTF-8 回退和用户词表无效；完整日记服务回归继续执行。
