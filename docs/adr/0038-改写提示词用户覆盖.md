# 0038 改写提示词用户覆盖

- 状态：提议；2026-10-06；C 提议，待 E/D 评审

## 决策

C-09 从 Hub 数据目录 `templates/prompts/rewrite.md` 加载用户同名覆盖。启动校验完整正整数版本、非空正文及 `{style}`、`{text}`；失败独立回退出厂版本，日志不含用户正文。复用 ADR 0034 的目录与回退机制，新增 `infra::templates::load_prompt` 供非安全提示词共用。

危机词表和禁用词表只认出厂版本；同意、占位符、保真和输出校验流程不变。没有修改出厂提示词内容；修改用户文件后重启生效。回退出厂仍失败则沿用服务不启动的错误路径。

## 影响

产品书 10 第 7 节、15 第 5 节补充 P-REWRITE 启动语义校验口径；不改变命令、事件或数据库。真实接口 E-REWRITE 仍待接口和人工评分。

## 验证

覆盖有效模板与渲染、缺失覆盖、版本/正文/占位符错误、非 UTF-8、出厂文件缺失；workspace 原有改写保真与危机回归测试继续执行。
