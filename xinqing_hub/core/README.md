# xinqing-hub-core
- 职责：Hub 的领域层和平台无关的基础层（FR-STA-01～08、FR-SAF-01 本地通道、08 第 5 节 V1/V3/V4/V5/V7、FR-AIG-02/05/07 的熔断/脱敏/预算、09 第 3 节数据库）。
- 对外接口：`pipeline::StatePipeline`（XQP 事件 → 窗口 → 特征 → 规则 → 融合）、`pipeline::replay`、`infra::xqp::XqpLink`（XQP 客户端：握手、2 秒重连、心跳超时断开、状态类下行消息重连后补发；传输由 `Connector` 提供，Windows 命名管道在外壳）、`sense::Sense`（实时感知任务：XQP 事件 → 流水线 → 状态快照、写库、总线事件、下发天气）、`care::ComfortService`（暖心话：订阅总线，主动关怀与负面自评的回应，P-COMFORT 生成与校验、模板兜底、频率控制，写 `comfort_log`；与外壳之间只走 `ComfortPort`）、`domain::comfort`（暖心话的触发判断、状态摘要、提示词、V1–V7 校验、模板选句）、`domain::comfort_feedback`（👍 / 👎 / 🔕 与连续 3 天负反馈自动降档）、`rewrite::RewriteService`（温柔改写：`rewrite_req` → 同意 ⑥ / 本地危机词表 / 可还原占位符 / P-REWRITE / V1、V4、V8 校验 → `rewrite_result`；`rewrite_done` → `rewrite_log`；与外壳之间只走 `RewritePort`，ADR 0028）、`domain::rewrite`（占位符 `mask` / `restore`、保真校验 `check` / `accept`、P-REWRITE 拼装）、`evening::EveningService`（晚间小结：到点、活跃 ≥ 30 分钟、人在电脑前时组装统计与本地结束语，与外壳之间只走 `EveningPort`，ADR 0029）、`domain::evening`（何时出、主导状态、天气色带、`evening.toml` 选句）、`letter::LetterService`（周信：周日 20:00 起写那周的信，同意 ④ 时 P-LETTER + 长度 / V4 / V9 校验、不过重写一次，否则或失败时用本地模板，与外壳之间只走 `LetterPort`，ADR 0030）、`domain::letter`（哪一周 `due_week`、一周统计 `stats`、V9 `facts_ok`、兜底模板 `LetterFallback`）、`diary::DiaryService`（情绪日记：草稿 P-DIARY 或空白模板、保存时判来源、日记里的危机识别，与外壳之间只走 `DiaryPort`，ADR 0031）、`domain::diary`、`schedule::ScheduleService`（日程与待办识别：上屏拼句 → L1 → Q-PLAN / Q-TODO → P-SCHEDULE / P-TODO 或本地规则 → 待确认，与外壳之间只走 `SchedulePort`，ADR 0032）、`reminder::ReminderService`（日程与待办提醒调度，`ReminderPort`）、`domain::agenda`（冲突、相似、`.ics`）、`domain::reminder`（提醒时刻与文案）、`domain::features::persist`（个人基线：启动和每天 04:00 用最近 7 天的窗口重算并写 `baseline` 表，重置基线）、`domain::explain`（状态解释 FR-STA-09：`build` 生成结构化解释，`ExplainCopy::render` 按 `explain.toml` 拼句）、`domain::safety::check_local`、`domain::validate::BannedWords`、`infra::store::Db`（含 `net_log`、`letter` 读写，只留最近 200 条；`Db::open_reader` 开只读连接）、`infra::store::DbWriter`（单写入口：普通数据排队批量提交，用户确认类数据 `write_sync` 同步写，ADR 0020）、`infra::gateway::AiGateway` 与 `NetLogEntry`（HTTP 实现在 `xinqing_hub/gateway`）；界面用的 `domain::status`（显示状态快照与天气映射）、`domain::consent`（六项单独同意）、`domain::settings`（设置键注册表 `KEYS`，默认值与取值范围，值有布尔 / 数字 / 字符串 / 字符串列表四种形态，ADR 0019；`caps` 读出每日预算上限；借用 `settings` 表的内部键 `INTERNAL_KEYS`）、`domain::dnd`（勿扰应用与安静时段的判断）；`domain::notify`（系统通知的文案与按钮 FR-NTF-01：`NotifyCopy::rest` 给小组件看不见时的休息提醒，读 `ui_copy.toml` 的 `[notify]`、`[rest]`；弹窗在外壳 `notify.rs`）；`domain::routine`（作息洞察 FR-REV-03：`record_active_minute` / `record_rest` 写 `daily_summary` 的使用时长、停止打字时间、休息提醒计数，`get` 给 `get_routine`）；`domain::demo`（演示模式 FR-DMO-03：`seed` 往新建的演示库写入“过去一周”，加速倍数 `SPEED`；加速时钟是 `infra::clock::ScaledClock`）；`research::ResearchService` 与 `domain::research`（研究模式 FR-DMO-04：每天 3 个邀请时刻 `plan`、进度 `Esm`；与外壳之间只走 `ResearchPort`）；`domain::retention`（FR-DAT-02 按 09 第 1 节保留期自动清理，什么时候跑由外壳 `cleanup.rs` 决定）；`infra::store::export`（FR-DAT-03 导出 zip：每表一个 JSON、`README.md`、带 SHA-256 的 `manifest.json`）。
- 依赖：只依赖 `xqp` 和通用库，**禁止**依赖 tauri / windows（NFR-MNT-03，见 docs/adr/0007）。可选特性 `specta` 只给外壳导出 TypeScript 类型用。
- 配置：读取 `hub_templates/` 中的 baseline_default、app_categories、explain、crisis_lexicon、banned_words、comfort、prompts/comfort.md。
- 数据：`migrations/0001_init.sql`、`0002_comfort_trigger.sql`（`comfort_log.trigger`，ADR 0015）；`window_features.features_json` 写入前检查只含数值和 null。
- 测试：`cargo test -p xinqing-hub-core`；`tests/crisis_parity.rs` 与 Python 参考实现对拍，`tests/features_parity.rs` 的窗口切分、特征和基线统计与 `eval/tools/features_ref.py` 对拍，`tests/replay_scripts.rs` 用合成脚本做端到端回归（TC-STA-06 口径），`tests/xqp_live.rs` 让进程内的假核心按真实节奏回放同样的脚本，核对握手、重连和实时识别结果与离线回放一致。
- 回放工具：`cargo run -p xinqing-hub-core --bin xq-replay -- <脚本> [--mock-jev] [--start-at 23:40] [--baseline 文件] [--json]`；切换窗口的下一行（JSON 里是 `explain` 字段）是状态解释。
- 隐私检查：窗口只存时间戳和类别，不存文字；进程名只用于分类，不落库、不出网；Q-STATE 请求按字段白名单过滤，文本字段先脱敏。
- 日程/待办：`domain::schedule::ScheduleRecognizer` 按 `schedule_patterns.toml` 做本地逐句初筛；`infra::store::Db` 提供结构化日程与待办写入、24 小时哈希去重、忽略时清空内容及待确认项清理。初筛候选原句只存在内存，不能写库。
